# Multi-AI Assistant

Vercel-ready Next.js app combining OpenAI, Gemini and a demo fallback.

## Run
npm install
npm run dev

## Environment variables
Copy `.env.example` to `.env.local` and add provider keys.

## Vercel
Import the GitHub repository into Vercel, then add the same environment variables in Project Settings → Environment Variables.

No artificial app credits are implemented. External provider quotas still apply.
